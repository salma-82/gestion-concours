1. MONOTONIE ET MAJORATIONS

1.1. Suite majorée, minorée, bornée

  • Une suite \((u_n)_{n \in I}\) est dite majorée s'il existe un réel \(M\) tel que : \(\forall n \in I, \quad u_n \le M\).
  • Une suite \((u_n)_{n \in I}\) est dite minorée s'il existe un réel \(m\) tel que : \(\forall n \in I, \quad u_n \ge m\).
  • Une suite \((u_n)_{n \in I}\) est dite bornée si elle est à la fois majorée et minorée (\(m \le u_n \le M\)), ce qui équivaut à : \(\exists M \ge 0, \quad |u_n| \le M\).

1.2. Monotonie d'une suite

  • Suite croissante : \(\forall n \in I, \quad u_{n+1} - u_n \ge 0 \iff u_{n+1} \ge u_n\).
  • Suite décroissante : \(\forall n \in I, \quad u_{n+1} - u_n \le 0 \iff u_{n+1} \le u_n\).
  • Suite constante : \(\forall n \in I, \quad u_{n+1} = u_n\).

2. SUITES ARITHMÉTIQUES ET GÉOMÉTRIQUES

Suite Arithmétique Suite Géométrique
Définition :
\(u_{n+1} = u_n + r \quad (r \in \mathbb{R})\) 		Définition :
\(u_{n+1} = q \times u_n \quad (q \in \mathbb{R})\)
Terme général :
\(u_n = u_p + (n - p)r\)
(Si \(p = 0\) : \(u_n = u_0 + nr\)) 		Terme général :
\(u_n = u_p \times q^{n-p}\)
(Si \(p = 0\) : \(u_n = u_0 \times q^n\))
Somme des termes :
\(S_n = u_p + u_{p+1} + \dots + u_n\)
\(S_n = \frac{(n - p + 1)(u_p + u_n)}{2}\) 		Somme des termes \((q \neq 1)\) :
\(S_n = u_p + u_{p+1} + \dots + u_n\)
\(S_n = u_p \times \frac{1 - q^{n - p + 1}}{1 - q}\)

Limite de la suite géométrique \(q^n\)

  • Si \(q > 1\), alors \(\lim_{n \to +\infty} q^n = +\infty\)
  • Si \(-1 < q < 1\), alors \(\lim_{n \to +\infty} q^n = 0\)
