Chapitre 6 : Les nombres complexes

1. Ensemble \(\mathbb C\) & forme algébrique

\(\mathbb C=\{z=a+ib\mid(a,b)\in\mathbb R^2\) et \(i^2=-1\}\)

  • Parties : \(\mathrm{Re}(z)=a\), \(\mathrm{Im}(z)=b\)
  • Conjugué : \(\bar z=a-ib\)

Propriétés du conjugué

  • \(\overline{z+z'}=\bar z+\bar z'\) ; \(\overline{z\times z'}=\bar z\times\bar z'\)
  • \(\overline{(z/z')}=\bar z/\bar z'\) ; \(\overline{z^n}=(\bar z)^n\)
  • \(z\bar z=a^2+b^2\)
  • \(z+\bar z=2\mathrm{Re}(z)\) ; \(z-\bar z=2i\mathrm{Im}(z)\)
  • \(z\in\mathbb R\iff z=\bar z\)
  • \(z\in i\mathbb R\iff\bar z=-z\)

2. Module d’un complexe

\(|z|=\sqrt{z\bar z}=\sqrt{a^2+b^2}\)

  • \(|z|^2=z\bar z\) ; \(|z|=|\bar z|=|-z|=|-\bar z|\)
  • \(|z\times z'|=|z|\times|z'|\) ; \(|z/z'|=|z|/|z'|\)
  • \(|z^n|=|z|^n\)
  • Inégalité triangulaire : \(|z+z'|\le|z|+|z'|\)

3. Trigonométrie remarquable

\(\theta\)0\(\frac\pi6\)\(\frac\pi4\)\(\frac\pi3\)\(\frac\pi2\)\(\pi\)
\(\cos\theta\)1\(\frac{\sqrt3}2\)\(\frac{\sqrt2}2\)\(\frac12\)0−1
\(\sin\theta\)0\(\frac12\)\(\frac{\sqrt2}2\)\(\frac{\sqrt3}2\)10
\(\tan\theta\)0\(\frac{\sqrt3}3\)1\(\sqrt3\)Nd0

Valeurs particulières (\(\frac\pi{12}\) et \(\frac\pi8\))

  • \(\cos\frac\pi{12}=\frac{\sqrt6+\sqrt2}4\) ; \(\sin\frac\pi{12}=\frac{\sqrt6-\sqrt2}4\) ; \(\tan\frac\pi{12}=2-\sqrt3\)
  • \(\cos\frac\pi8=\frac{\sqrt{2+\sqrt2}}2\) ; \(\sin\frac\pi8=\frac{\sqrt{2-\sqrt2}}2\) ; \(\tan\frac\pi8=\sqrt2-1\)

4. Formes trigonométrique & exponentielle

Soit \(z\ne0\) :

  • Trigonométrique : \(z=|z|(\cos\theta+i\sin\theta)=[|z|;\theta]\)
  • Exponentielle : \(z=|z|e^{i\theta}\)
  • Passage : \(\cos\theta=\frac a{|z|}\) et \(\sin\theta=\frac b{|z|}\)

Propriétés des arguments

  • \(\arg(zz')\equiv\arg(z)+\arg(z')\ [2\pi]\)
  • \(\arg(z/z')\equiv\arg(z)-\arg(z')\ [2\pi]\)
  • \(\arg(1/z)\equiv-\arg(z)\ [2\pi]\) ; \(\arg(\bar z)\equiv-\arg(z)\)
  • \(\arg(z^n)\equiv n\arg(z)\) ; \(\arg(-z)\equiv\pi+\arg(z)\)

Opérations sous la forme \([r;\theta]\)

  • \([r;\theta][r';\theta']=[rr';\theta+\theta']\) ; \(\frac1{[r;\theta]}=[\frac1r;-\theta]\)
  • \([r;\theta]/[r';\theta']=[\frac r{r'};\theta-\theta']\) ; \([r;\theta]^n=[r^n;n\theta]\)
  • \(\overline{[r;\theta]}=[r;-\theta]\) ; \(-[r;\theta]=[r;\pi+\theta]\)

Astuces de formes géométriques rapides (\(a>0\))

  • \(a=[a;0]\) ; \(-a=[a;\pi]\) ; \(\pm ai=[a;\pm\frac\pi2]\)
  • \(a\pm ia\sqrt3=[2a;\pm\frac\pi3]\) ; \(-a\pm ia\sqrt3=[2a;\pm\frac{2\pi}3]\)
  • \(a\sqrt3\pm ia=[2a;\pm\frac\pi6]\) ; \(-a\sqrt3\pm ia=[2a;\pm\frac{5\pi}6]\)
  • \(a\pm ia=[\sqrt2a;\pm\frac\pi4]\) ; \(-a\pm ia=[\sqrt2a;\pm\frac{3\pi}4]\)

5. Propriétés de \(e^{i\theta}\) & Euler

  • \(e^{i\theta}=\cos\theta+i\sin\theta\) ; \(e^{-i\theta}=\cos\theta-i\sin\theta\)
  • \(e^{i0}=1\) ; \(e^{i\pi}=-1\) ; \(e^{i\frac\pi2}=i\) ; \(e^{-i\frac\pi2}=-i\)
  • \(|e^{i\theta}|=1\) ; \(\arg(e^{i\theta})\equiv\theta\ [2\pi]\) ; \(\overline{e^{i\theta}}=e^{-i\theta}\)
  • Moivre : \((\cos\theta+i\sin\theta)^n=\cos(n\theta)+i\sin(n\theta)\)

Formules d’Euler

\(\cos\theta=\frac{e^{i\theta}+e^{-i\theta}}2\) ; \(\sin\theta=\frac{e^{i\theta}-e^{-i\theta}}{2i}\)

\(e^{i\theta}+e^{-i\theta}=2\cos\theta\) ; \(e^{i\theta}-e^{-i\theta}=2i\sin\theta\)

Technique de l’angle moitié

  • \(1+e^{i\theta}=2\cos(\frac\theta2)e^{i\frac\theta2}\) ; \(1-e^{i\theta}=-2i\sin(\frac\theta2)e^{i\frac\theta2}\)
  • \(\frac{1-e^{i\theta}}{1+e^{i\theta}}=-i\tan(\frac\theta2)\)
  • \(e^{i\alpha}+e^{i\beta}=2\cos(\frac{\alpha-\beta}2)e^{i\frac{\alpha+\beta}2}\)
  • \(e^{i\alpha}-e^{i\beta}=2i\sin(\frac{\alpha-\beta}2)e^{i\frac{\alpha+\beta}2}\)

6. Équations du second degré

Soit \(az^2+bz+c=0\) \((a,b,c\in\mathbb R)\), et \(\Delta=b^2-4ac\).

  • Si \(\Delta>0\) : \(z=\frac{-b\pm\sqrt\Delta}{2a}\) (2 solutions réelles)
  • Si \(\Delta=0\) : \(z=\frac{-b}{2a}\) (1 solution double)
  • Si \(\Delta<0\) : \(z=\frac{-b\pm i\sqrt{-\Delta}}{2a}\) (2 sol. complexes conjuguées)
  • Propriétés : \(z_1+z_2=-\frac ba\) et \(z_1z_2=\frac ca\)

Racines usuelles

  • \(z^2=a\ (a>0)\iff z=\pm\sqrt a\)
  • \(z^2=-a\ (a>0)\iff z=\pm i\sqrt a\)
  • \(z^2=i\iff z=\pm\frac{\sqrt2}2(1+i)\)
  • \(z^2=-i\iff z=\pm\frac{\sqrt2}2(1-i)\)

Racines cubiques de l’unité (\(z^3=1\))

Solutions : \(1\), \(j=-\frac12+i\frac{\sqrt3}2=e^{i\frac{2\pi}3}\), \(\bar j=j^2\).

Propriétés : \(j^3=1\) et \(1+j+j^2=0\).

7. Suites complexes & repères

Somme géométrique : \(1+z+z^2+\cdots+z^n=\frac{z^{n+1}-1}{z-1}\) \((z\ne1)\)

8. Géométrie complexe

  • Vecteur : \(z_{\vec{AB}}=z_B-z_A\) ; Distance : \(AB=|z_B-z_A|\)
  • Milieu : \(z_I=\frac{z_A+z_B}2\) ; Gravité : \(z_G=\frac{z_A+z_B+z_C}3\)
  • Barycentre : \(z_G=\frac{\alpha z_A+\beta z_B+\gamma z_C}{\alpha+\beta+\gamma}\)

Configurations géométriques

  • Angle : \((\vec{AB},\vec{AC})\equiv\arg\left(\frac{z_C-z_A}{z_B-z_A}\right)\ [2\pi]\)
  • Alignement : \(A,B,C\) alignés \(\iff\frac{z_B-z_A}{z_C-z_A}\in\mathbb R\)
  • Parallélisme : \((AB)\parallel(DC)\iff\frac{z_C-z_D}{z_B-z_A}\in\mathbb R\)
  • Orthogonalité : \((AB)\perp(DC)\iff\frac{z_C-z_D}{z_B-z_A}\in i\mathbb R\)
  • Cocycliques : \(A,B,C,D\) sur le même cercle si \(\left(\frac{z_C-z_A}{z_C-z_B}\times\frac{z_D-z_B}{z_D-z_A}\right)\in\mathbb R\)

Nature des triangles via \(R=\frac{z_C-z_A}{z_B-z_A}\)

  • \(R=[1;\theta]\iff\) isocèle en \(A\)
  • \(\mathrm{Re}(R)=0\iff\) rectangle en \(A\)
  • \(R=[1;\pm\frac\pi2]\iff\) rectangle et isocèle en \(A\)
  • \(R=[1;\pm\frac\pi3]\iff\) équilatéral

9. Ensembles de points

  • \(|z-z_A|=r\iff\) cercle \(\mathcal C(A,r)\)
  • \(|z-z_A|\le r\) (resp. \(\ge r\)) \(\iff\) intérieur (resp. extérieur) de \(\mathcal C\)
  • \(|z-z_A|=|z-z_B|\iff\) médiatrice de \([AB]\)
  • \(\frac{z-z_A}{z-z_B}\in i\mathbb R\iff\) cercle de diamètre \([AB]\) privé de \(B\)
  • \(\left|\frac{z-z_A}{z-z_B}\right|=R\ (R\ne1)\iff\) cercle de diamètre \([EF]\) avec : \(z_E=\frac{z_A+Rz_B}{1+R}\) et \(z_F=\frac{z_A-Rz_B}{1-R}\)

10. Transformations géométriques

Forme générale : \(z'=az+b\)

  • Translation \(\vec u(z_{\vec u})\) : \(z'=z+z_{\vec u}\)
  • Homothétie \(\Omega(\omega),k\) : \(z'-\omega=k(z-\omega)\)
  • Rotation \(\Omega(\omega),\theta\) : \(z'-\omega=e^{i\theta}(z-\omega)\)

Identification rapide

  • Si \(a=1\) : translation de vecteur d’affixe \(b\).
  • Si \(a\in\mathbb R\setminus\{1\}\) : homothétie de rapport \(a\), centre \(\omega=\frac b{1-a}\).
  • Si \(a\notin\mathbb R\) et \(|a|=1\) : rotation d’angle \(\arg(a)\), centre \(\omega=\frac b{1-a}\).
