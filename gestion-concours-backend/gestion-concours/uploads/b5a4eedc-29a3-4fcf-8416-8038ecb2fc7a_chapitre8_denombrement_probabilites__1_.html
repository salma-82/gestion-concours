Chapitre 8 : Dénombrement et probabilités

A.1 Cardinal d’un ensemble fini

Le nombre d’éléments d’un ensemble fini \(E\) est appelé le cardinal de \(E\), noté \(\mathrm{Card}(E)\).

A.2 Principe fondamental du dénombrement

Soit une expérience nécessitant \(k\) choix successifs. Si le \(1^{er}\) choix se fait de \(n_1\) façons, le \(2^e\) de \(n_2\) façons, …, le \(k^e\) de \(n_k\) façons, alors le nombre total de résultats possibles est : \[n_1\times n_2\times\cdots\times n_k\]

A.3 Arrangements sans répétition

Sélection ordonnée de \(p\) éléments parmi \(n\) (\(0\le p\le n\)) : \[A_n^p=n\times(n-1)\times\cdots\times(n-p+1)=\frac{n!}{(n-p)!}\]

Cas particuliers : \(A_n^1=n\) ; \(A_n^0=1\).

A.4 Permutations

Arrangement de \(n\) éléments parmi \(n\) (\(p=n\)) : \[A_n^n=n!=n\times(n-1)\times\cdots\times2\times1\]

Conventions : \(0!=1\) ; \(1!=1\).

A.5 Arrangements avec répétition

Le nombre de sélections ordonnées de \(p\) éléments parmi \(n\) avec répétition possible est égal à \(n^p\).

A.6 Combinaisons

Sélection non ordonnée de \(p\) éléments parmi \(n\) : \[C_n^p=\frac{A_n^p}{p!}=\frac{n!}{p!(n-p)!}\]

Propriétés : \(C_n^1=n\), \(C_n^n=1\), \(C_n^p=C_n^{n-p}\).

A.7 Types de tirages et importance de l’ordre

Type de tirageNombreOrdre
Avec remise\(n^p\)Important
Sans remise\(A_n^p\)Important
Simultané\(C_n^p\)Sans importance

A.8 Coefficient d’ordre (anagrammes)

Pour arranger \(p\) places contenant \(p_1\) éléments de type A, \(p_2\) de type B, et \(p_3\) de type C avec \(p_1+p_2+p_3=p\) : \[\text{Nombre d’arrangements}=\frac{p!}{p_1!\times p_2!\times p_3!}\]

B.1 Propriétés générales

Soit \(\Omega\) l’univers fini associé à une expérience.

  • \(P(\Omega)=1\) ; \(P(\emptyset)=0\) ; \(0\le P(A)\le1\).
  • Événement contraire : \(P(\bar A)=1-P(A)\).
  • Union : \(P(A\cup B)=P(A)+P(B)-P(A\cap B)\).
  • Équiprobabilité : \(P(A)=\frac{\mathrm{Card}(A)}{\mathrm{Card}(\Omega)}\).

B.2 Probabilité conditionnelle

Probabilité de \(B\) sachant \(A\) (avec \(P(A)\ne0\)) : \[P_A(B)=\frac{P(A\cap B)}{P(A)}\implies P(A\cap B)=P(A)\times P_A(B)\]

B.3 Arbre des possibilités pondéré

L’arbre modélise la succession des événements :

  • \(A\to B\) : \(P(A\cap B)=P(A)\times P_A(B)\)
  • \(A\to\bar B\) : \(P(A\cap\bar B)=P(A)\times P_A(\bar B)\)
  • \(\bar A\to B\) : \(P(\bar A\cap B)=P(\bar A)\times P_{\bar A}(B)\)
  • \(\bar A\to\bar B\) : \(P(\bar A\cap\bar B)=P(\bar A)\times P_{\bar A}(\bar B)\)

B.4 Loi des probabilités totales

Les événements \(A\) et \(\bar A\) forment une partition de \(\Omega\). Pour tout événement \(B\) : \[P(B)=P(B\cap A)+P(B\cap\bar A)\] \[P(B)=P(A)\times P_A(B)+P(\bar A)\times P_{\bar A}(B)\]

B.5 Indépendance de deux événements

  • \(A\) et \(B\) sont indépendants \(\iff P(A\cap B)=P(A)\times P(B)\).
  • Propriété : Si \(P(A)\ne0\), \(A\) et \(B\) sont indépendants \(\iff P_A(B)=P(B)\).

B.6 Épreuves répétées (schéma de Bernoulli)

Soit \(A\) un événement de probabilité \(p\). La probabilité de réaliser exactement \(k\) fois l’événement \(A\) au cours de \(n\) répétitions indépendantes est : \[P(X=k)=C_n^k\,p^k(1-p)^{n-k}\] où \(n\) est le nombre total de répétitions dans les mêmes conditions.
